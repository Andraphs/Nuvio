# Nuvio — Personal Finance Dashboard

Static site consisting of a landing page and a dashboard demo.

## Files

- `index.html` — landing page
- `dashboard.html` — dashboard demo

The landing page's **Live Demo** and **Get Started Free** buttons open `dashboard.html`.

## Publish with GitHub Pages

1. Create a GitHub repository for this site.
2. Upload these files from this folder to the repository root (keep `index.html`, `dashboard.html`, and `.nojekyll` together).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`, and save.
5. Open the Pages URL shown in Settings. The landing page is served from `index.html`; **Live Demo** opens `/dashboard.html`.

This is a static front end. It does not connect to a bank or store live financial data. The pages load some visual assets and styling from external CDNs.
